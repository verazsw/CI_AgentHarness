# Competitor Analysis Agent

Extracts, structures, and summarizes competitor clinical trial data for immunology.

## How to Use

1. Open Claude Code in this folder
2. Ask what you need

**Examples:**
- "Extract efficacy data from this press release: [URL]"
- "Summarize this competitor readout for AD"
- "What does this BNMA forest plot show?" (with image)
- "Generate a slide deck for the new dupilumab data"
- "Add this data to our database for EASI-75"

## Prerequisites

- Claude Code with `lilly-code` access
- That's it

## Current Supported Indications in Immunology

AtD, Psoriasis, UC, RA, CRSwNP, PsA, Crohn's, SLE, Asthma, COPD, IPF, Allergic Rhinitis
